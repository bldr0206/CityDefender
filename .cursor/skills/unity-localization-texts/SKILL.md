# Unity Localization Texts

## Правило

Все тексты, которые могут быть локализованы и видны игроку в игре, делай локализируемыми.

Используем стандартный Unity Localization package.

Дебаг не локализируем, только игру.

## Что локализовать

- UI-тексты: кнопки, заголовки, панели, статусы, ошибки для игрока.
- Диалоги, реплики, нарратив, квесты, цели, описания.
- Туториалы, подсказки, уведомления, сообщения победы/поражения.
- Тексты в `TextMeshProUGUI`, `TMP_Text`, префабах, сценах и runtime-коде, если их видит игрок.

## Что не локализовать

- `Debug.Log`, `Debug.LogWarning`, `Debug.LogError`.
- Внутренние технические сообщения, которые игрок не видит.
- Editor-only тексты, названия переменных, ключи, enum-значения и комментарии.
- Временные диагностические строки для разработки.

## Как писать

- Не хардкодь игровые строки в C# для вывода игроку.
- Для UI предпочитай `LocalizedString` / `LocalizeStringEvent` и строки из таблиц Unity Localization.
- Для новых строк добавляй понятные ключи в подходящую string table проекта.
- Если видишь существующий игровой hardcoded text в редактируемом участке, по возможности переведи его на локализацию в рамках текущей задачи.
- Не добавляй самодельную систему локализации поверх Unity Localization package.

## Перед завершением

Проверь отредактированный фрагмент:

- Остались ли игровые строки, видимые игроку, захардкоженными?
- Подходят ли ключи локализации по смыслу и не завязаны ли они на текущий русский/английский текст?
- Не попали ли debug/editor-only строки в локализацию без необходимости?
